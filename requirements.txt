# RegDelta runtime dependencies. Pinned exactly, for the same reason
# .github/workflows/evals.yml pins its tools: unpinned, what runs in CI is
# whatever the resolver picked that morning, and "identical code passed
# yesterday" stops being information.
#
# This file did not exist until M03. Everything through M02 ran on stdlib +
# boto3, so dependencies were ambient — which was survivable at four packages
# and is not at twenty-five. If you add one, add it here and say why.

# AWS SDK. The only runtime dependency through M02: S3, S3 Vectors, DynamoDB,
# Bedrock, SSM. AOSS's data plane is hand-signed on top of botocore's SigV4
# (src/retrieval/aoss_client.py) rather than via a client.
boto3==1.43.54

# Agent graph (SPEC/03, M03). Verified to resolve on Python 3.14.3 with cp314
# binary wheels — no build-from-source step. Pulls langchain-core and ~20
# transitive packages; that cost was accepted deliberately, see
# docs/adr/0010 if one is written, and the M03 evidence pack either way.
#
# NOT included and deliberately so: langchain, langchain-community,
# langchain-aws. Bedrock is called through boto3 Converse directly
# (src/baseline/naive.py, src/retrieval/rerank.py, and the graph nodes), so a
# provider wrapper would add a second way to do the thing this repo already
# does one way.
langgraph==1.2.11

# API surface (SPEC/04, M04). The stack is the spec's choice, not the
# implementer's: SPEC/04 line 3 names "src/api/api.py — FastAPI + Mangum on
# Lambda". Mangum is the ASGI-to-Lambda adapter, so one app object serves both
# the deployed function and the local test client with no second code path —
# which matters here because the loopback shim (evals/serve_local.py) already
# exists and a second HTTP implementation is a second thing to keep honest.
#
# Pulls starlette and pydantic; both were already present transitively and are
# now first-order. No uvicorn: nothing in this repo serves ASGI over a socket.
# The deployed path is Mangum-on-Lambda and the test path is
# fastapi.testclient, which drives the app in-process without a server.
fastapi==0.141.1
mangum==0.21.0
